# Source

Fixture essays are from the Hewlett Foundation's Automated Student
Assessment Prize (ASAP) training set (`training_set_rel3.tsv`,
essay_set 1: persuasive letters, US grades 7-10), as mirrored at
https://github.com/tim-hub/Automated-Essay-Scoring

The essays are de-identified student writing released for research.
IDs below are the original `essay_id` values, so anyone can trace each
fixture back to the public dataset.
